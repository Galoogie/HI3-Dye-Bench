Mix dyes before committing in game or find a recipe from a hex.

Installation:
Download the HI3 Dye Bench html file.

Open it just like you would any other program. The file will open directly in your browser, but runs completely offline.


The Mixer:

Add any ingredients you want, the color wheel and result panel will dynamically update as you go.
Ingredients can be sorted alphabetically or by their hue. Ingredients with flat colored swatches provide both hue and saturation but no darkening, striped colored swatches provide both hue, saturation, and darkening, grey striped swatches only provide darkening.
The ingredient dropdown can be navigated by mouse or keyboard controls.


Color Finder:

Enter a valid hex code and it will attempt to find up to 14 of the closest match and provide recipes for those matches. Clicking on a row will add it to the mixer.
Note that the color finder will label hex codes at most one step on a single channel as an exact match. Visually, these hex codes will still look visually indistinguishable next to the provided hex.


Note on Certain Colors:

Some colors, usually ones that are both highly saturated and very bright, can not be reached in game due to how the game calculates colors. The tool will do it's best to tell you when a provided hex code is not reachable and why, but it will also provide you with closest matches.
